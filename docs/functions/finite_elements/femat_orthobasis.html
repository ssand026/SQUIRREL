femat_orthobasis

(memoized) Returns the matrix that converts between the full and orthonormal basis

Syntax:

[B] = femat_orthobasis(pts,tri)

Description:

 (memoized) Returns the matrix that converts between the full and orthonormal basis
 
 The orthobasis matrix is equal to the product of the nullspace matrix and the 
 square root of the overlap matrix.

This function calls:

  • femat_nullspace (memoized) Returns the finite-element nullspace matrix
  • femat_overlap (memoized) Returns the finite-element overlap matrix

This function is called by:

  • FEmat Returns the specified finite-element matrix

Subfunctions:

  • function [B] = femat_orthobasis_main(pts,tri)

bary_integral

Computes the barycentric integral coefficients

Syntax:

[intCoeffs,varargout] = bary_integral(Ndim, Nterm, ignore)

Description:

 Computes the barycentric integral coefficients
 
 The output depends on the number of spatial dimensions and the total number of 
 integration terms. The optional argument "ignore" will exclude the corresponding 
 barycoordinate from the integral.

This function calls:

  • npermsk For a set containing "n" distinct elements, return all possible permutations of length "k"

This function is called by:

  • FEmat Returns the specified finite-element matrix
  • femat_overlap (memoized) Returns the finite-element overlap matrix
  • setup_operator Returns a function that converts the scalar coefficient into its operator form.
  • setup_poisson Initializes the solver for the Poisson equation.

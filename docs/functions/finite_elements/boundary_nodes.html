boundary_nodes

Returns the logical index corresponding to nodes on the mesh boundary

Syntax:

[bnodes] = boundary_nodes(pts,tri)

Description:

 Returns the logical index corresponding to nodes on the mesh boundary

This function calls:

This function is called by:

  • FEmat Returns the specified finite-element matrix
  • femat_nullspace (memoized) Returns the finite-element nullspace matrix
  • mesh_smooth Improves the quality of a mesh by shifting each node towards the center of its connected neighbors

femat_overlap

(memoized) Returns the finite-element overlap matrix

Syntax:

[M] = femat_overlap(pts,tri)

Description:

 (memoized) Returns the finite-element overlap matrix

This function calls:

  • bary_integral Computes the barycentric integral coefficients
  • simplex_vol (memoized) computes the hypervolume of each simplex in the mesh

This function is called by:

  • FEmat Returns the specified finite-element matrix
  • femat_orthobasis (memoized) Returns the matrix that converts between the full and orthonormal basis

Subfunctions:

  • function [M] = femat_overlap_main(pts,tri)

setup_operator

Returns a function that converts the scalar coefficient into its operator form.

Syntax:

[convertFunc] = setup_operator(pts,tri)

Description:

 Returns a function that converts the scalar coefficient into its operator form.

This function calls:

  • bary_integral Computes the barycentric integral coefficients
  • simplex_vol (memoized) computes the hypervolume of each simplex in the mesh

This function is called by:

Subfunctions:

  • function [V] = conversion_func(coeff)

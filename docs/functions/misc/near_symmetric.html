near_symmetric

Determine if a matrix is symmetric within the given tolerance.

Syntax:

[out] = near_symmetric(A,tol)

Description:

 Determine if a matrix is symmetric within the given tolerance.

 INPUTS:
    A: input matrix
    tol (optional): value between 0 and 1 
 
 OUTPUT:
    +1 if A is symmetric
    -1 if A is skew-symmetric
     0 if A is non-symmetric

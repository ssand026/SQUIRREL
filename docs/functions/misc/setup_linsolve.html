setup_linsolve

Returns a function for solving the system of linear equations A*x = b.

Syntax:

[solverFunc] = setup_linsolve(A,dim,method)

Description:

 Returns a function for solving the system of linear equations A*x = b.
 This prevents repeated calculation of any preconditioning steps. For small
 systems where extreme accuracy is not needed, use the method "preinvert";
 otherwise, use the method "decompose".

This function calls:

This function is called by:

  • setup_poisson Initializes the solver for the Poisson equation.

0002 % Returns a function for solving the system of linear equations A*x = b.
0003 % This prevents repeated calculation of any preconditioning steps. For small
0004 % systems where extreme accuracy is not needed, use the method "preinvert";
0005 % otherwise, use the method "decompose".
0006 arguments
0007     A (:,:) double {mustBeFinite}
0008     dim (1,1) double {mustBeMember(dim,[1,2])} = 1;
0009     method string {mustBeMember(method,["decompose","preinvert","full"])} = "decompose"
0010 end
0011 switch method
0012     case "decompose"
0013         dA = decomposition(A);
0014         if dim==1; solverFunc = @(b) dA \ b; end
0015         if dim==2; solverFunc = @(b) b / dA; end
0016     case "preinvert"
0017         iA = inv(A);
0018         if dim==1; solverFunc = @(b) iA * b; end
0019         if dim==2; solverFunc = @(b) b * iA; end
0020     case "full"
0021         % not recommended
0022         if dim==1; solverFunc = @(b) A \ b; end
0023         if dim==2; solverFunc = @(b) b / A; end
0024 end
0025 end

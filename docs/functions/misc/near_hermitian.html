near_hermitian

Determine if a matrix is hermitian within the given tolerance.

Syntax:

[out] = near_hermitian(A,tol)

Description:

 Determine if a matrix is hermitian within the given tolerance.

 INPUTS:
    A: input matrix
    tol (optional): value between 0 and 1 
 
 OUTPUT:
    +1 if A is hermitian
    -1 if A is skew-hermitian
     0 if A is non-hermitian

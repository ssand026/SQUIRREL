to_basis

Converts the inputted data into the specified basis.

Syntax:

[data] = to_basis(basis,data,shape,B)

Description:

 Converts the inputted data into the specified basis. 
 The inputted data can take the form of a matrix, or an array/pagearray containing
 row or column vectors. The input "B" corresponds to the basis conversion
 matrix for the desired transformation.

This function calls:

This function is called by:

  • FE_init Computes all components of the finite-element Hamiltonian in the specified basis.
  • drop_distance Drops elements from the Hamiltonian using a distance-based criterion
  • drop_neighbor Drops elements from the Hamiltonian using a connection-based criterion

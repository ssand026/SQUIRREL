FEmat

Returns the specified finite-element matrix

Syntax:

[out] = FEmat(pts, tri, matType, scalarC, vectorC)

Description:

 Returns the specified finite-element matrix

 INPUTS:
    pts: mesh node locations
    tri: mesh triangulation
    matType (string): type of matrix to construct
    scalarC: scalar/tensor coefficient for the matrix
    vectorC: vector coefficient for the matrix

 SEE ALSO: FEMAT_NULLSPACE, FEMAT_ORTHOBASIS, FEMAT_OVERLAP, PARPOOL

This function calls:

  • coeff_eval Evaluates the input as a finite-element coefficient.
  • bary_integral Computes the barycentric integral coefficients
  • baryvectors (memoized) Computes the barycentric vector corresponding to each vertex in the mesh
  • boundary_nodes Returns the logical index corresponding to nodes on the mesh boundary
  • coeff_expand Expands the coefficient so its value is given for the vertices of each simplex
  • femat_nullspace (memoized) Returns the finite-element nullspace matrix
  • femat_orthobasis (memoized) Returns the matrix that converts between the full and orthonormal basis
  • femat_overlap (memoized) Returns the finite-element overlap matrix
  • simplex_vol (memoized) computes the hypervolume of each simplex in the mesh
  • mesh_faces Returns the list of all unique faces contained within the mesh
  • npermsk For a set containing "n" distinct elements, return all possible permutations of length "k"

This function is called by:

  • FE_dipole Constructs the dipole-moment matrices for spatially-invariant electric or magnetic fields.
  • FE_init Computes all components of the finite-element Hamiltonian in the specified basis.
  • setup_poisson Initializes the solver for the Poisson equation.
